dockerfile
===================

Image creation
=====================
We can create a docker file and inside that we will write all the instrauctions so this way if you ask
the docker daemon to use this file and generate the image what daemon will do is it will try to read all
instructions that you have given this file read it line by line and convert it into a image so that is 
how instead of you running all steps you can just run this single file or you can ask the daemon to read this file
take all the instructions and create a image in the background
